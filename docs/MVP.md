# Mapa grobów — MVP 0.1

## Cel
Publiczny katalog grobów i osób z prywatną warstwą relacji rodzinnych.

## Zakres
- OpenStreetMap / Leaflet z pinezkami grobów
- Wyszukiwanie osób i cmentarzy
- Karty grobów ze zdjęciami i współrzędnymi
- Wiele osób w jednym grobie
- Relacje rodzinne i towarzyskie
- Prywatne ulubione i notatki (IndexedDB)
- Responsywny interfejs i otwieranie nawigacji
- GitHub Pages + GitHub Actions

## Zasady danych
- Nie publikować danych żyjących krewnych bez ich zgody.
- Rozdzielić osoby, groby i relacje.
- Nie wymyślać współrzędnych, dat ani powiązań.
- Odróżniać dane z inskrypcji od relacji ustnych i hipotez.
- Przed upublicznieniem repozytorium przejrzeć dane i prawa do zdjęć.

## Pilot
Cmentarz w Jabłonce; pięć grobów, pierwsze rekordy w data/jablonka.json. Zdjęcia czekają na import.
